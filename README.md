# ナンバー抽選（1〜8）

タップで 1〜8 の数字をランダムに1つずつ決めていく、スマホ／タブレット横画面向けの抽選アプリです。

## 使い方
1. 画面をタップ → 数字が高速で切り替わる（ドラムロール音）
2. もう一度タップ → 数字が1つ決定（パン！）
3. タップ → 残りの数字で再び高速表示 → タップで決定…を8つ全部出るまで繰り返し

| ボタン | 動作 |
|---|---|
| ↶ 1つ戻す | 直前に決まった数字を取り消す（高速表示中なら止めて元に戻す） |
| ⟲ 最初から | 確認のうえ、全てリセット |
| 🔊 / 🔇 | 音のオン・オフ |
| ⛶ 全画面 | 全画面表示（Android / iPad） |

- 途中でページを閉じたり再読み込みしても、結果は端末に保存されて続きから再開できます。
- 下の丸に、出た数字が順番に表示されます。

## 画像
- `images/logo.png` … 左側に表示するロゴ
- `images/background.jpg` … 背景のコンクリート質感
どちらも同じ名前で差し替えれば変わります。

## 音の変更（任意）
音は自動生成していますが、`sounds/drumroll.mp3`（ループ再生）と `sounds/pan.mp3` を置くとそちらが優先されます。

## iPhone で全画面にするには
iPhone の Safari は全画面ボタンに対応していないため、
Safari の「共有」→「ホーム画面に追加」で追加し、ホーム画面のアイコンから開いてください（アドレスバー無しで表示されます）。

## GitHub Pages で公開する手順
1. GitHub で新しいリポジトリ（例: `ddo-solo-battle`）を作成
2. このフォルダをプッシュ
   ```bash
   git remote add origin https://github.com/<ユーザー名>/ddo-solo-battle.git
   git push -u origin main
   ```
3. リポジトリの **Settings → Pages** で Branch を `main` / `/(root)` にして Save
4. 数分後 `https://<ユーザー名>.github.io/ddo-solo-battle/` で開けます
